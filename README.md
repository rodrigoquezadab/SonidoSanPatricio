# SonidoSanPatricio

Guía Técnica y Documentación del Sistema de Audio y Amplificación del **Templo Parroquial San Patricio de Las Condes** (Santiago, Chile).

Integrador original del sistema: **Novotic** ([www.novotic.cl](https://www.novotic.cl)).

---

## 📖 Contenido del Repositorio

* **[index.html](index.html):** Aplicación web interactiva e imprimible (formato PDF) con inventario de equipos, diagrama vectorial SVG de cableado y mapeo de zonas acústicas, instrucciones de conexión de software y protocolos de encendido.
* **[CONTEXT.md](CONTEXT.md):** Documento técnico exhaustivo de contexto, arquitectura de hardware, configuración de red IP, parámetros de DSP, diagnóstico del canal B2 y enlaces de soporte técnico oficial.

---

## 🛠️ Equipamiento Principal del Rack

1. **Biamp Nexia CS:** Procesador digital de señales (DSP 10x6) y matriz acústica central.
2. **Crown XTi 1002 (Amplificador A):** Potencia para la Nave Central (Zonas A1 delantera y A2 central/trasera).
3. **Crown XTi 1002 (Amplificador B):** Potencia para monitoreo (Zona B1 retorno al altar y Zona B2 coro).

---

## 🚀 Visualización Rápida

Para ver la guía gráfica en cualquier navegador web:
1. Abre el archivo `index.html` en tu navegador favorito (Chrome, Edge, Firefox).
2. Para generar el manual en PDF físico o digital, presiona el botón **Imprimir / PDF** en la barra superior.
